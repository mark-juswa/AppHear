# Emulator controlled run, 2026-11-10

Numbers-only logs of the three controlled scenarios (one hand / two apart / two touching) and `analysis.json`.
The raw `*.log` files are stored as `*.log.gz` because `*.log` is git-ignored; `gunzip -k` them to reproduce
`python -m eval.hand_diagnostics.analyze_scenarios <dir> <name> ...`. The `*.crash.log` files were empty (no crashes) and are not stored.
Screenshots contain the subject's face and are intentionally not in the repository.
